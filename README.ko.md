## Linkjob AI란?

Linkjob AI는 실시간 면접, 코딩 평가, 면접 연습을 위한 데스크톱 **AI 면접 도우미**입니다. 모든 회의 플랫폼이나 브라우저 기반 테스트에서 작동하는 보이지 않는 오버레이로 실시간 답변을 제공하며, **Dual-Device Mode**를 사용하면 휴대폰으로 바로 받을 수도 있습니다.

과거 프로젝트를 설명하든, 알고리즘을 풀든, 시스템 설계 질문에 답하든, Linkjob AI는 생각을 정리하고 접근 방식을 명확하고 자신 있게 전달하도록 돕습니다.

**Windows, macOS, Linux**에서 사용할 수 있습니다.

## ✨ Linkjob AI를 선택하는 이유

### 100% 보이지 않고 감지되지 않음

AI Interview Copilot은 모든 플랫폼에서 완전한 은밀 모드로 작동하며, 화면 공유 중에도 조용히 백그라운드에서 실행됩니다. 보이는 인터페이스나 팝업이 없어 시선 추적이나 감독 시스템의 감지를 걱정하지 않고 실시간 AI 지원을 활용할 수 있습니다. 면접은 완전히 자연스러운 상태로, 집중하고 자신감 있게 임하세요.

### Dual-Device Mode — 휴대폰으로 답변 확인

**새 기능.** 데스크톱 앱이 백그라운드에서 계속 실행되는 동안 AI 답변을 휴대폰으로 보내, 데스크톱 모니터링 소프트웨어의 감지를 피할 수 있습니다. 동일한 실시간 지원을 두 번째 화면에서 받아보세요.

### 모든 플랫폼에서 작동

Linkjob AI는 모든 회의 및 평가 플랫폼에서 보이지 않습니다. **Zoom 데스크톱 앱**만 한 번 설정을 켜면 되고, 다른 플랫폼에서는 추가 설정이 전혀 필요하지 않습니다.

### 당신처럼 들리는 답변

이력서와 직무 정보를 추가하면 당신의 경험, 기술, 목표 직무에 맞춘 답변을 받을 수 있습니다. Linkjob AI는 당신의 배경을 바탕으로 관련 사례와 자연스러운 표현을 제안해, 후속 질문에서도 구체적이고 일관된 답변을 유지합니다.

### 대화에 집중

유용한 안내를 손이 닿는 곳에 두면서도 시선을 피하지 않고 대화의 흐름을 놓치지 않습니다. AI를 미세 조정해 응답이 주제에서 벗어나지 않고 알차고 관련성 있게 유지하세요.

## 🚀 핵심 기능

### 실시간 면접 가이드

Linkjob AI는 면접 질문이 나오는 즉시 이해하고, 답변을 구성하고 후속 질문에 대응할 수 있도록 명확하고 구조화된 가이드를 제공합니다.

[실시간 AI 면접 코파일럿](https://www.linkjob.ai/interview-copilot/)을 살펴보세요.

### 코딩 면접 코파일럿

코딩 문제, 알고리즘, 복잡도와 엣지 케이스, 디버깅, 코드 최적화, 시스템 설계 트레이드오프에 대한 실시간 지원을 받습니다. 코파일럿은 다음에 대해 보이지 않습니다.

- **화면 공유** — 공유 세션 중에도 보이는 창이나 오버레이가 없습니다.
- **활성 탭 감지** — 브라우저 샌드박스 밖에서 실행되는 네이티브 데스크톱 앱입니다.
- **커서 추적** — 보이지 않는 커서와 감지되지 않는 전역 단축키를 사용합니다.
- **웹캠 모니터링** — 코드 편집기 위로 끌어다 놓을 수 있는 투명한 플로팅 창입니다.

또한 **실시간 화면 캡처**(전체 화면 및 부분), 한 대화에 여러 스크린샷, 면접관의 후속 질문에 대한 상황 기반 답변을 지원합니다.

[AI 코딩 면접 도우미](https://www.linkjob.ai/coding-interview-copilot/)를 살펴보세요.

### 브라우저 테스트 및 온라인 퀴즈 지원

브라우저 기반 평가와 온라인 퀴즈 중에 Linkjob AI를 사용해 즉각적인 문제 분석과 구조화된 해결책을 얻으면서, 평가 플랫폼에서는 감지되지 않습니다.

### AI 모의 면접 연습

실전 전에 행동·기술·코딩 면접을 AI 피드백과 함께 연습하고, 이력서와 목표 직무를 반영해 답변을 다듬으세요.

### Smart Screenshot

화면에서 중요한 부분만 캡처해 대화에 넣어 빠르고 정확한 맥락을 얻습니다.

### 최신 플래그십 AI 모델

OpenAI, Anthropic, Google, xAI의 최상위 모델(GPT, Claude, Gemini, Grok 제품군 포함)로 작동하며, 유료 요금제에서는 무제한으로 사용할 수 있습니다. 모델을 전환해 응답 속도와 추론 깊이의 균형을 맞추세요.

[현재 모델 라인업 및 요금제 세부정보](https://www.linkjob.ai/pricing/)를 확인하세요.

### 모든 면접 형식에 대응

일반, 코딩, 전화, HireVue, 행동, 기술, 시스템 설계, 컨설팅, 금융, 퀀트 면접에 맞춘 지원을 제공합니다.

## 🚀 빠른 시작

1. 시스템에 맞는 버전을 **다운로드하고 설치**합니다.
2. **Linkjob AI를 열고 로그인**한 뒤 요금제를 선택하거나 구독을 활성화합니다.
3. 사용할 기능(오디오 입력, 화면 캡처, 필요 시 Zoom 설정)에 맞춰 **오디오와 권한을 구성**합니다.
4. 요금제에 포함된 **AI 모델을 선택**하고 이력서, 직무 설명 또는 커스텀 안내를 추가합니다.
5. **모드를 선택**합니다 — 실시간 면접 오버레이, Dual-Device Mode, 코딩 코파일럿.
6. **연습 세션을 실행**해 오디오 캡처, 스크린샷 지원, 응답 품질, 화면 공유 동작을 확인합니다.

첫 실제 세션 전에 [**필수 설정**](./required-setup.md) 체크리스트(Zoom 구성, 오디오 출력, VPN, System Prompt 준비)를 확인하세요.
