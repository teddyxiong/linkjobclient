## Linkjob AI란?

Linkjob AI는 실시간 면접, 코딩 테스트, 면접 연습을 위한 데스크톱 **AI 면접 도우미**입니다. 실시간 오디오 이해, 스크린샷 분석, 개인화된 AI 응답을 플로팅 데스크톱 인터페이스에 통합합니다.

과거 프로젝트를 설명하든, 알고리즘을 풀든, 시스템 설계 질문에 답하든, Linkjob AI는 생각을 정리하고 접근 방식을 전달하는 데 도움을 줍니다.

**Windows, macOS, Linux**에서 사용할 수 있습니다.

## ✨ 주요 기능

### 실시간 면접 지원

면접 질문이 나오는 즉시 구조화된 제안을 받습니다. 핵심 포인트를 파악하고 답변을 정리하며 후속 질문에 대응하는 데 활용하세요.

[실시간 AI 면접 코파일럿](https://www.linkjob.ai/interview-copilot/)을 살펴보세요.

### 스크린샷 기반 코딩 도움

화면의 코딩 문제를 캡처하여 문제 분해, 접근 방식 선택, 코드 생성, 오류 디버깅, 성능 개선에 대한 도움을 받습니다. AI 안내로 알고리즘, 엣지 케이스, 기술 설명을 다뤄보세요.

[AI 코딩 면접 도우미](https://www.linkjob.ai/coding-interview-copilot/)를 살펴보세요.

### 배경에 맞춘 개인화 답변

이력서와 직무 설명을 추가해 AI에 관련 맥락을 제공합니다. 프롬프트를 커스터마이즈해 제안이 경험, 목표 직무, 면접 시나리오에 더 구체적으로 맞도록 만드세요.

### 스텔스 데스크톱 오버레이

이동 가능한 반투명 오버레이로 안내를 작업 영역 가까이에 유지하세요. 지원되는 화면 공유 및 녹화 캡처에서 벗어나도록 설계되었습니다.

플랫폼별 설정이 중요합니다. 사용 전에 필수 설정을 완료하고 화면 공유 구성을 테스트하세요.

### 다양한 AI 모델

요금제에서 제공하는 GPT, Claude, Gemini, Grok 모델 중에서 선택하세요. 포함된 모델 간에 전환하며 응답 속도와 추론 깊이의 균형을 맞출 수 있습니다.

[현재 모델 라인업 및 요금제 세부정보](https://www.linkjob.ai/pricing/)를 확인하세요.

### 행동·기술·모의 면접

행동 질문, 코딩 챌린지, 시스템 설계 논의, 모의 면접 연습에 도우미를 활용하세요. 면접 형식과 직무에 맞게 준비를 조정할 수 있습니다.

### 다국어 지원

여러 언어로 실시간 면접 지원을 받을 수 있으며, 응답은 면접 언어에 맞춰 제공됩니다.

## 🚀 빠른 시작

1. 시스템에 맞는 버전을 **다운로드하고 설치**합니다.
2. **Linkjob AI를 열고** 대시보드 안내에 따라 체험 또는 요금제를 활성화합니다.
3. 사용할 기능(오디오 입력, 화면 캡처 등)에 맞춰 **오디오와 권한을 구성**합니다.
4. 요금제에 포함된 **AI 모델을 선택**하고 이력서, 직무 설명 또는 커스텀 안내를 추가합니다.
5. **연습 세션을 실행**하여 오디오 캡처, 스크린샷 도움, 응답 품질, 화면 공유 동작을 확인합니다.

첫 실제 세션 전에 [**필수 설정**](./required-setup.md) 체크리스트(Zoom 구성, 오디오 출력, VPN, System Prompt 준비)를 확인하세요.

현재 **30분 무료 체험**이 제공됩니다. 체험 정보와 요금제 옵션은 [요금 페이지](https://www.linkjob.ai/pricing/)를 방문하세요.
